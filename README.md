# PBEL-Project
Project Topic : Smart Rice Farming System

The Smart Rice Farming System is an IoT and AI-based agriculture project designed to improve rice cultivation through real-time environmental monitoring, remote irrigation control, and automated rice leaf disease detection.

The IoT subsystem uses an ESP32 and multiple sensors to monitor soil moisture, temperature, humidity, rain conditions, and light intensity. Sensor data is uploaded to the Adafruit IO cloud platform, enabling remote monitoring and irrigation pump control through a dashboard.

The AI subsystem uses a trained YOLO-based model to detect three common rice leaf diseases: Rice Blast, Rice Blight, and Brown Spot, using image-based detection.

Currently, both subsystems operate independently, with future scope for integration into a unified smart agriculture platform.

**Technologies Used:** ESP32, IoT, Adafruit IO, Python, YOLO, Computer Vision, and Machine Learning.

Developed as part of the Project Based Experiential Learning (PBEL) program at DES Pune University, Pune.
